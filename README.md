**Projects**

The folder broadly covers projects I did as part of Financial Computing (C++), Trading Risk, Sell Side Modeling (CCR) at NYU 

Quick summary on Projects:
**Basket Options**: Arithmetic average call on a three-stock basket, Monte Carlo (C++)

**Exotic Options** - Asian Options: Asian call, plain vs control variate Monte Carlo (C++)

**Russell 3000 Quant Analysis based on Earnings**: Earnings-surprise event study (C++)

**VaR - Market Risk**: VaR, ES, backtesting and stress testing (Python)

**XVA Pricing** - Interest rate Swap: CVA, DVA, FVA, MVA for a swap (Python)

Quick summary on some standalone projects:
**OptionPricer02.cpp**: Binomial tree (CRR) pricer for European and digital calls and puts

**Integral in C++ with Trapezoidal Approx.cpp**: Definite integral by trapezoid and Simpson rules

**Option Pricing and Option greeks.ipynb**: Black-Scholes call and put price and Greeks

**Monte Carlo Stock Price Simulation.ipynb**: One-year Monte Carlo price paths for INFY.NS

**Portfolio Optimization**- Efficient Frontier, Sharpe Ratios.ipynb: 5,000-portfolio efficient frontier and max Sharpe for MSFT, PG, S&P 500

needs g++ and make on Linux, macOS or WSL for C++ files; Python with jupyter for notebooks
